# P0 MVP 范围

本文档从完整 PRD 中拆出第一版最小可用范围，目标是先做出一个能安装、能常驻后台、能截图、能编辑、能复制粘贴的 Windows 版本。

## MVP 目标

- 安装后双击即可运行，不要求用户安装 Python 或其他运行环境。
- 应用常驻系统托盘，使用全局快捷键唤起截图。
- 截图后进入单窗口编辑器，默认区域框选。
- 编辑结果实时写入剪贴板，用户可以直接在微信、QQ、浏览器聊天框等位置 `Ctrl + V` 粘贴图片。
- 支持常用标注、文字、打码、模糊、马赛克。
- 提供 OCR、翻译、手动长截图作为第一版增强功能。

## P0 功能清单

| 模块 | 功能 | MVP 描述 | 当前状态 |
| :--- | :--- | :--- | :--- |
| 安装 | Windows 安装包 | 输出单个 `.exe` 安装程序，安装后自动放到本地应用目录并启动。 | 已实现 |
| 运行 | 系统托盘 | 后台驻留，托盘菜单包含截图、长截图、设置、退出。 | 已实现 |
| 运行 | 全局快捷键 | 默认 `Ctrl + Shift + A`，支持在设置中修改。 | 已实现 |
| 截图 | 区域截图 | 快捷键触发后拖拽选择区域，完成后进入编辑器。 | 已实现 |
| 截图 | 全屏截图 | 托盘菜单可直接截取所有屏幕。 | 已实现 |
| 截图 | 多次截图单窗口管理 | 默认只打开一个编辑器窗口，第二次截图追加到左侧列表。 | 已实现 |
| 截图 | 长截图 | 先框选固定区域，再按次数和延迟连续采集并纵向拼接。 | 已实现 |
| 输出 | 默认复制到剪贴板 | 截图完成后自动复制图片；编辑后实时更新剪贴板。 | 已实现 |
| 输出 | 保存图片 | 支持保存为图片文件。 | 已实现 |
| 编辑 | 矩形、圆形标注 | 支持颜色和粗细。 | 已实现 |
| 编辑 | 文字标注 | 点击图片直接输入文字，支持调整文字大小和颜色，可再次选中修改。 | 已实现 |
| 编辑 | 手动打码 | 支持黑色遮盖、模糊、马赛克。 | 已实现 |
| 编辑 | 撤销 | 支持基础撤销。 | 已实现 |
| 编辑 | 箭头、直线、画笔 | 支持箭头、直线、自由画笔和高亮笔，并支持线宽调节。 | 已实现 |
| 智能 | OCR | 使用 Windows 本地 OCR 识别截图文字并复制。 | 已实现 |
| 智能 | 翻译 | 使用在线翻译接口对 OCR 结果进行翻译。 | 已实现 |
| 智能 | 一键智能打码 | 基于 Windows OCR 自动识别手机号、邮箱、身份证、IP 并添加马赛克。 | 已实现 |
| UI | 工具栏 | 悬浮式图标按钮、颜色选择、大小调节、主动关闭按钮。 | 已实现 |

## 第一版暂不做

以下内容保留在完整 PRD 中，但不放进第一版 MVP：

- macOS `.dmg` 安装包
- 自动更新
- 开机自启默认开启
- 窗口自动识别截图
- 全自动滚动截图
- 放大镜、坐标像素、固定尺寸、延时截图
- 步骤序号、局部放大、背景美化
- 人脸、车牌识别打码
- 上传图床
- 多张钉图、缩放、旋转

## 当前版本发布检查

发布前建议逐项确认：

- 安装包可以在一台没有 Python 环境的 Windows 电脑上安装并启动。
- 托盘图标存在，退出后进程完全关闭。
- 快捷键修改后立即生效，重启后仍保留。
- 截图后能直接在聊天窗口 `Ctrl + V` 粘贴图片。
- 文字工具可以连续输入多次，并且可以修改已有文字。
- 编辑任意标注后，剪贴板图片随之更新。
- 长截图能按用户设置的次数和延迟生成长图。
- OCR 功能在安装版里可用。
