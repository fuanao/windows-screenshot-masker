# 智能截图工具 - 产品需求文档

## 一、产品概述

### 1.1 产品定位

一个集 **智能捕捉、便捷标注、一键打码、高效输出** 于一体的桌面截图工具，旨在提升用户信息截取、处理和分享的整个流程效率。

### 1.2 目标用户

- 需要频繁截图沟通的设计师、产品经理、开发者
- 有隐私保护需求的商务、金融、医疗从业者
- 日常办公需要截图标注的普通用户

## 二、安装与运行形态

用户故事：作为用户，我希望能方便地安装应用，并让它在后台安静运行，以便随时用快捷键唤出截图。

### 2.1 交付格式

| 需求项 | 详细描述 | 优先级 |
| :--- | :--- | :--- |
| 平台安装包 | 交付为标准桌面安装程序：Windows 为 `.exe` 安装包（NSIS 或 MSI）；macOS 为 `.dmg` 镜像，支持拖拽到应用程序文件夹。 | P0 |
| 便携版 | 可选提供免安装的 `.zip` 压缩包，解压即用，供高级用户使用。 | P2 |

### 2.2 运行时行为

| 需求项 | 详细描述 | 优先级 |
| :--- | :--- | :--- |
| 系统托盘驻留 | 安装启动后，应用最小化到系统托盘（Windows）或菜单栏（macOS），在后台静默运行。仅在截图时弹出编辑器界面。 | P0 |
| 开机自启 | 支持“开机自动启动”选项，安装后默认开启，可在设置中关闭。 | P1 |
| 全局快捷键注册 | 注册系统级全局快捷键，即使应用窗口不在前台，也能响应截图热键。所有快捷键必须支持用户完全自定义，避免冲突。 | P0 |
| 单实例运行 | 确保同一时间只有一个应用实例在运行。重复双击 exe 时，应激活已有实例，而不是打开第二个。 | P1 |

### 2.3 系统权限与依赖

| 需求项 | 详细描述 | 优先级 |
| :--- | :--- | :--- |
| 屏幕捕获权限 | 请求并引导用户授予操作系统要求的屏幕录制/捕获权限（尤其在 macOS 上必须处理）。 | P0 |
| 辅助功能权限 | 请求辅助功能权限，用于窗口自动识别和滚动截图等高级功能。 | P1 |
| 剪贴板读写 | 需要读写系统剪贴板，用于复制截图图片和 OCR 提取的文字。 | P0 |
| 自包含运行环境 | 安装包内包含所有依赖，用户无需安装任何额外框架。 | P0 |
| 自动更新引擎 | 内置自动更新机制，启动时检查新版本，提示用户下载并静默升级。 | P1 |

## 三、核心功能模块

### 3.1 截图捕捉模块

用户故事：作为用户，我想要通过多种方式精准截取屏幕内容，以便能捕获到任何我想分享的信息。

| 功能点 | 详细描述 | 优先级 |
| :--- | :--- | :--- |
| 基础截图模式 | 支持快捷键触发，提供区域截图、窗口截图、全屏截图、多显示器支持。 | P0 |
| 滚动截图 | 在窗口或网页中，能自动或手动触发滚动，截取整个长页面，生成长图。 | P0 |
| 截图辅助 | 截图时显示放大镜辅助对齐，显示坐标像素；支持固定尺寸/比例截图；支持延时截图；可设置是否包含鼠标光标。 | P1 |

### 3.2 图片编辑与标注模块

用户故事：作为用户，我想在截图上进行清晰的标注，以便能突出我想表达的重点。

| 功能点 | 详细描述 | 优先级 |
| :--- | :--- | :--- |
| 基础图形 | 提供矩形、圆形、箭头、直线、画笔工具，支持自定义颜色和粗细。 | P0 |
| 文字标注 | 支持在任意位置添加文字，可自定义字体、大小、颜色。 | P0 |
| 高亮与模糊 | 高亮笔（半透明马克笔效果）和手动马赛克/模糊涂抹工具。 | P0 |
| 步骤序号 | 提供带圆圈的序号图标，可连续添加，用于指示操作流程。 | P1 |
| 局部放大 | 圈选一个区域，在旁边自动生成该区域的放大镜效果，突出细节。 | P1 |
| 重编辑与撤销 | 支持完整的撤销/重做操作栈。所有已绘制的标注元素，都可以被再次选中、移动、修改或删除。 | P1 |
| 背景美化 | 为截图添加背景色、渐变或毛玻璃效果；为截图本身添加圆角和阴影，提升视觉质感。 | P2 |

### 3.3 一键智能打码模块

用户故事：作为用户，我想要一键识别并遮盖截图中的敏感信息，以确保我分享的内容不会泄露隐私。

| 功能点 | 详细描述 | 优先级 |
| :--- | :--- | :--- |
| 智能识别打码 | 点击后，自动识别并打码邮箱、手机号、身份证号、IP 地址、人脸、车牌、自定义关键词。 | P0 |
| 打码样式 | 识别到的区域统一使用模糊或马赛克效果，并可调节模糊强度。 | P0 |
| 打码确认与手动修正 | 打码后，被打码区域保持半透明高亮状态。用户可取消、新增、修正，确认后最终应用。 | P0 |
| 分类快捷打码 | 提供“仅打码手机号”、“仅打码人脸”等快捷指令。 | P1 |
| 智能填充打码 | 手动拉框打码时，可自动提取选区周围的背景色来填充，让遮盖更自然。 | P2 |
| 安全分享检查 | 保存或复制截图时，若检测到未处理的敏感信息，提示用户确认。 | P2 |

### 3.4 文字识别与输出模块

用户故事：作为用户，我想提取截图中的文字，并能将处理好的截图快速保存或分享出去。

| 功能点 | 详细描述 | 优先级 |
| :--- | :--- | :--- |
| OCR 文字识别 | 识别截图中的所有文字，支持复制文字、打码后复制。 | P1 |
| 贴图/钉图 | 截图编辑完成后，可将图片钉在桌面最顶层，作为悬浮窗口参考。可支持多张图同时钉，支持缩放、旋转、一键关闭。 | P1 |
| 输出与分享 | 支持本地保存、复制到剪贴板、上传图床并复制 URL。 | P1 |

## 四、非功能性需求

| 需求项 | 详细描述 |
| :--- | :--- |
| 交互体验 | 所有核心功能快捷键可自定义；所有可点击、可拖拽元素需有明确 hover 和激活状态；工具栏采用极简风格，悬浮在截图区域旁。 |
| 性能要求 | 截图启动延迟应小于 200ms；一键打码处理 1080P 截图应小于 2 秒；编辑器操作需流畅。 |
| 技术栈建议 | 为便于跨平台，建议采用 Electron、React、TypeScript，并结合原生 Node 模块实现高性能截图与图像处理。OCR 和智能打码可集成 Tesseract.js 或云服务 API。 |
